# QR Coder Privacy Site

Files:
- `index.html` — Turkish + English Privacy Policy
- `account-deletion.html` — external account/data deletion request resource

## GitHub Pages quick deploy
1. Create a new **public** GitHub repository, for example `qr-coder-privacy`.
2. Upload `index.html` and `account-deletion.html` to the repository root.
3. Commit to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Branch: `main`; Folder: `/ (root)`; click **Save**.
7. Wait for GitHub Pages to publish the site.
8. The privacy URL will normally be:
   `https://<github-username>.github.io/qr-coder-privacy/`
9. The external account-deletion resource will normally be:
   `https://<github-username>.github.io/qr-coder-privacy/account-deletion.html`

After publishing:
- Update the AdMob European regulations message privacy-policy URL.
- Update Google Play Console privacy-policy URL.
- Add the account-deletion URL to Play Console Data safety / account deletion fields.
- Keep the privacy policy and Play Data safety declarations consistent with the app.
